General Instructions

Please read the following instructions carefully before starting the assessment.

  1. The assessment consists of multiple modules. Each module has its own timer. Once a module's time is over, it is submitted automatically.
  2. The test is adaptive: the difficulty of the next question depends on how you answered the current one.
  3. You cannot go back to a previous question and you cannot skip a question. Select an option and click Submit Answer to move ahead.
  4. There is no negative marking. Unattempted questions when time runs out are scored as zero.
  5. Once you submit a module, you cannot return to it.
  6. In Automata Fix you correct buggy code; in Automata Pro you write complete solutions. Use Compile & Run to test against sample cases and Submit Code to evaluate against all test cases (including hidden ones). You may switch between the problems freely within the module.
  7. Do not switch tabs, minimise the window or exit full screen. All such activity is recorded.
  8. The test runs in full screen. If you exit, the test is hidden until you click Enter Full Screen. Every exit is recorded.
The timer starts the moment you click Start on each module. Keep pen and paper ready, and switch off distractions — treat this exactly like the real thing.
